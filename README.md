# Autonomous Problem-Solving / 自主问题处理

AI Agent 自主问题解决方法论，融合了 ReAct、Reflexion、Plan-and-Solve、AutoGPT、Self-Refine 等框架的精华。

## 核心理念

用户提出需求后，AI Agent 全程自主闭环，不中途停下来让用户测试。

## 核心循环

**观察 → 思考 → 行动 → 观察结果 → 反思**

0. 定义成功标准（防止无限循环）
1. 先搜经验（复用已有知识）
2. 评估方法（风险评估 + 环境检查）
3. 写过程文档（记录一切）
4. 读写循环（用文档纠正自己）
5. 失败反思（分析根因，不只是"失败了"）
6. 不重复错误（记录过的失败方法绝不重试）
7. 质量验证（跑通 ≠ 做好）
8. 总结沉淀（可复用的经验和代码模板）

## 独特之处

- **文档驱动** — 用文件系统而非短期记忆来驱动循环，跨 session 可复用
- **失败即学习** — 记录"什么方法不行"和"为什么不行"，下次跳过
- **经验库机制** — `/root/notes/` 或 workspace 下的经验文档可搜索复用
- **迭代上限** — 最多10轮后换个大方向，防止钻牛角尖

## 融合的框架

| 框架 | 吸收的精华 |
|------|-----------|
| Chain of Thought | 逐步推理，不想当然 |
| ReAct | 观察→思考→行动→观察的循环 |
| Reflexion | 失败后结构化反思，分析根因 |
| Self-Refine | 完成后自检质量，不是跑通就算完 |
| Plan-and-Solve | 先规划再执行，评估风险 |
| AutoGPT | 定义成功标准，防止无限循环 |

## 使用方式

直接将 SKILL.md 的内容复制到你的 AI Agent 的系统提示词（SOUL.md / AGENTS.md）中即可。
